# 새 브랜드 후보 B2 검토 (2026-10-05)

사용자 요청(2026-10-05): "기존 확정(S2+W2)보다 새 컨셉아트의 무지개 꽃, 남색 별, 손글씨 봄별 로고와 앱 아이콘이 더 마음에 든다. 새 브랜드 후보로 검토하고 최종 확인 후 기존 결정을 갱신."

상태: **후보(최종 확인 전)**. DESIGN §1의 확정(S2+W2)과 앱 코드는 아직 그대로다. 아래 "최종 확인" 항목이 채워지면 DESIGN, tokens, Q-LOGO를 갱신하고 파생 에셋과 코드를 교체한다.

## 1. 후보가 무엇인가

- 심볼: 무지개 그라디언트 꽃(둥근 꽃잎이 모인 덩어리, 아래쪽에 별 모양으로 파인 자리) + 겹쳐 놓인 둥근 남색 별 + 작은 네 갈래 반짝임.
- 워드마크: 손글씨 "봄별"(별 아래로 길게 빠지는 곡선) + 넓게 띄운 "BOMBYEOL".
- 앱 아이콘: 밝은(아이보리) 바탕, 남색 바탕 두 벌. 남색 바탕에서는 별이 밝은 하늘색.
- 출처: `concept/logo-concepts.png`의 **01(심볼형) 심볼 + 06(한글 서체 활용형) 워드마크** 조합을 원안 그대로 살린 것. 2026-10-02에 고른 방향("1번 심볼 + 6번 계열 타이포", DESIGN §1)과 **같은 방향**이고, 그때는 단색 S2 + W2로 다시 그렸다. 즉 이번 변경은 새 방향이 아니라 **원안의 질감(그라디언트, 손글씨)으로 되돌리는 것**에 가깝다.
- 받은 파일: 보드에서 잘라낸 PNG뿐(로고 235x201, 심볼 84x64, 앱 아이콘 116px). **이 크롭은 적용하지 않는다(사용자 결정)**. 새 SVG 로고와 1024px 앱 아이콘이 오면 교체한다.

## 2. 사용자 결정 (2026-10-05, 이 후보와 함께)

1. 그라디언트 허용 범위는 **브랜드 에셋(로고, 앱 실행 아이콘, 파비콘, 공유 이미지)에 한정**. 일반 UI(버튼, 면, 배경, 카드)의 그라디언트 금지는 유지.
2. 앱 안 아이콘은 기존 규칙 유지: 24px 격자, 획 1.75, 둥근 끝(§10.5). 새 로고와 도형 관계를 맞춰야 하는 아이콘만 따로 검토한다.
3. 함께 받은 그라디언트 장식 아이콘 8개(달, 하트, 반짝임, 잎, 별, 별 두 개, 구름, 꽃)로 앱 아이콘을 **교체하지 않는다**.
4. 가족 일러스트 2장(봄 들판, 밤 호숫가)은 빈 화면과 로그인 영역에 쓰고, 문구는 그림 밖에 둔다(Q-ILLUST 해결, 코드 적용 2026-10-05).

## 3. 가능한가 - 검토 결과

가능하다. 막는 기술 제약은 없고, 바뀌는 범위가 정해져 있다.

| 영역 | 바뀌는 것 | 판단 |
|---|---|---|
| 로고 파일 | `image-asset/logo/*`(10종), 앱 `public/brand/logo/*` | SVG만 오면 같은 파일 이름으로 바꿔 끼운다. 코드는 파일 경로만 쓴다(`components/brand/logo.tsx`) |
| 앱 아이콘, 파비콘 | `image-asset/icon/*`, 앱 `src/app/icon.svg`, `apple-icon.png`, `favicon.ico`, `public/brand/icon/*`, `manifest.ts` | 1024px 원본(가능하면 SVG)에서 다시 뽑는다 |
| 공유 이미지 | `image-asset/og/og-image.*`, 앱 `public/brand/og/og-image.png` | 새 로고로 다시 만든다 |
| 토큰 | `tokens.json`에 브랜드 그라디언트 색 멈춤점 추가(v1.2) | 멈춤점은 봄 팔레트(pink #F2A7B3, yellow #F4CB6E, green #A9C88C, sky #A8D8E8) 안에서 고른다. UI에서는 쓰지 않는다는 주석을 같이 둔다 |
| 문서 | DESIGN §1, §3 규칙 4, §7, §12의 그라디언트 줄, Q-LOGO, `brand/asset-index.md`, `brand-guide.md` | 최종 확인 뒤 한 번에 갱신 |
| 앱 안 아이콘 | 아래 §4의 3개만 검토 | 획 규칙은 그대로 |

## 4. 앱 안 아이콘 - 도형 관계 검토

§10.5는 "심볼의 세 도형에서 뽑는다, 로고가 바뀌면 아이콘도 다시 뽑는다"이다. 17개 중 심볼에서 온 것은 3묶음뿐이다.

| 아이콘 | 지금 | 새 심볼과의 관계 | 할 일 |
|---|---|---|---|
| `today`, `todayOn`(오늘 탭) | 꽃잎 원 네 개(S2 꽃) | 새 꽃은 둥근 꽃잎 덩어리 + 별 모양으로 파인 자리. 원 네 개와 실루엣이 다르다 | **다시 그린다**. 새 꽃의 바깥 윤곽을 1.75 선으로(그라디언트 없이). 채운 상태는 currentColor 한 색 |
| `star`, `starOn`(이야기 탭, 별 하나) | 다섯 갈래 별, 끝이 둥근 | 새 별도 둥근 다섯 갈래. 통통한 정도만 다를 수 있다 | SVG를 받은 뒤 비율을 맞출지 판단(작은 수정) |
| `spark`(마일스톤, 질문 표식) | 네 갈래 반짝임 | 같은 도형. 원안은 초록, 지금은 골드 | 도형은 그대로. 색은 UI 규칙(골드는 남색 위 강조)대로 유지 |
| 나머지 12개(우리, 하트, 말풍선, 더하기, 화살표, 연필, 닫기, 확인, 재생) | 같은 획 규칙 | 심볼과 무관 | 그대로 |

## 5. 위험과 확인할 것

1. **작은 크기에서 그라디언트가 뭉개진다.** 파비콘 16, 32px에서 무지개가 얼룩처럼 보일 수 있다. 작은 크기용 단순판(그라디언트를 2~3색 면으로 줄인 것)을 따로 받는 것이 안전하다.
2. **단색판이 꼭 필요하다.** 안드로이드 알림 작은 아이콘(흰 실루엣), 단색 로고(`monochrome`), 인쇄, PDF 표지용. 그라디언트로는 대신할 수 없다.
3. **어두운 바탕판.** 남색 별은 남색 바탕(이야기 탭, 다크 모드)에서 안 보인다. 받은 앱 아이콘처럼 별을 밝은 하늘색(또는 silver #C7CEDD)으로 바꾼 `-dark` 판이 필요하다.
4. **마스크형 앱 아이콘 안전 영역.** 안드로이드는 아이콘을 원, 둥근 사각형으로 자른다. 1024px 기준 가운데 약 80%(지름 820px 원) 안에 심볼이 들어와야 한다.
5. **워드마크 서체 라이선스.** 컨셉 보드는 손글씨 서체(온글잎 계열)를 예시로 들었다. Q-FONT에서 "온글잎 제작 서비스 종료, 라이선스 미확인"이 기록되어 있다. 워드마크는 **직접 그린 윤곽(경로)**이어야 하고, 기존 서체를 따라 그린 것이면 그 서체의 로고 사용 허락을 확인해야 한다. 디자이너에게 확인 받는다.
6. **반짝임 색.** 원안은 초록, 지금 로고는 골드. 로고 안에서는 어느 쪽이든 되지만, UI의 골드 강조(§3)와 맞추려면 골드가 자연스럽다.
7. **"봄 색 두 종 이상 동시 사용 금지"(§3 규칙 2)와 무지개 꽃.** 로고는 브랜드 에셋 예외로 본다(사용자 결정 1). UI 면에는 여전히 적용.

## 6. 디자이너에게 받을 것 (교체 조건)

| 파일 | 형식 | 비고 |
|---|---|---|
| 심볼 | SVG(밝은 바탕, 어두운 바탕) | 그라디언트는 SVG `linearGradient`로. 래스터 이미지를 SVG 안에 넣지 않는다 |
| 심볼 작은 크기판 | SVG | 16, 32px에서 읽히는 단순판 |
| 단색 심볼, 단색 로고 | SVG | 한 색(남색, 흰색) |
| 워드마크 | SVG(밝은, 어두운) | 글자는 윤곽선 경로. 서체 출처 명시 |
| 가로형, 세로형 로고 | SVG(밝은, 어두운) | 지금 `primary`, `stacked`와 같은 쓰임 |
| 앱 아이콘 | 1024px PNG + 가능하면 SVG, 밝은, 남색 | 모서리를 둥글게 자르지 않은 꽉 찬 정사각형(플랫폼이 자른다), 안전 영역 지킴 |
