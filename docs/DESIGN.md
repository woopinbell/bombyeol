## 1. 브랜드 에셋 (임시 후보, 미확정)

`image-asset/`은 아이디어 탐색 산출물이다. 어디에 쓸지는 정해지지 않았다.

- `concept/logo-concepts.png` — 6안 탐색 보드(의사결정 기록). 대화에서 "1번 심볼 + 6번 계열 타이포" 방향을 골랐다.
- `logo/*.svg` — 실사용 후보. **주의: 생성된 SVG는 보드의 1번 심볼(꽃 + 별의 일체형 그라디언트)을 단순 도형(원 4개 + 별)으로 재구성한 거친 버전**이라 보드의 완성도에 못 미친다. 로고 재제작 여부는 폴리시 단계에서 결정(`OPEN_QUESTIONS.md` Q-LOGO).
- `icon/*`, `og/*` — PWA 아이콘·공유 이미지 파생본. 심볼이 확정되면 다시 파생해야 한다.
- 워드마크 폰트: 보드에서는 손글씨풍(온글잎 '이는', '박다현체')이 언급되나 **온글잎 폰트 제작 서비스는 종료**됐고 일부 폰트의 웹폰트 사용 라이선스는 폰트별로 확인이 필요하다(연구 문서 §5).

## 3. 색 토큰 (초안)

원본: `image-asset/palette/colors.css`. 아래는 **역할과 접근성 규칙**을 덧붙인 것이다(대비비는 WCAG 공식으로 계산, 2026-10-01).

| 토큰 | 값 | 역할 |
|---|---|---|
| `paper` | #F7F1E6 | 기본 배경(한지 아이보리) |
| `ink` | #2C2621 | 기본 글자(먹빛) — paper 위 13.3:1 |
| `ink-muted` | #6F6860 | 보조 글자 — paper 위 4.9:1 (AA 통과, **AAA(7:1) 아님**) |
| `night-navy` | #232B4D | 별 영역 배경·제목 — paper 위 12.3:1 |
| `night-indigo` | #34406B | 별 영역 보조면 — paper 위 8.9:1 |
| `night-silver` | #C7CEDD | "우리" 탭 연결 요소(구분선·테두리) |
| `starlight-gold` | #E8C77A | 별 영역 강조점 — **navy 위 8.5:1은 OK, paper 위 1.45:1은 글자 불가** |
| `spring-pink/green/yellow/sky` | #F2A7B3 / #A9C88C / #F4CB6E / #A8D8E8 | 봄 영역 포인트 — **paper 위 1.4~1.7:1: 글자·아이콘 단독 사용 불가**, 면·배지 배경으로만, 그 위 글자는 `ink` |

### 사용 규칙
1. **글자는 항상 `ink`/`navy`(paper 배경) 또는 `paper`/`gold`(navy 배경)**. 봄 색을 paper 위 글자에 쓰지 않는다(대비 실패).
2. 봄 색은 **소량 포인트**: 배지·마일스톤 칩·상황 카드 면. 한 화면에 봄 색 두 종 이상 동시 사용 금지(브랜드 가이드의 "모든 요소에 파스텔 동시 적용 금지" 계승).
3. 다크(별) 모드: 이야기 탭은 navy가 기본 배경. 전체 다크 모드는 `night-navy` 계열로 매핑하고 글자는 `paper`. 골드는 질문 카드·"답변 완료" 같은 소량 강조.
4. 그라디언트·그림자를 UI 전반에 쓰지 않는다(브랜드 가이드 Don't).
5. 상태 색(오류·성공)은 토큰에 아직 없다 — 필요해지면 먼저 이 표에 추가.

## 4. 타이포그래피

- 본문·UI: **Pretendard**(hamkke에서 검증). 어르신 화면은 기본 본문을 **18px 이상**으로 시작하고 사용자 글자 크기 설정(설정 시트)을 제공. 시스템 글자 크기(Dynamic Type/Android 글꼴 크기)를 존중한다.
- 손글씨(아이/조부모 구분): **미확정**. 아이 = 둥근 손글씨, 조부모 = 차분한 손글씨라는 대화의 아이디어는 채택 방향이나, 후보 폰트의 웹폰트 라이선스·파일 용량·한글 커버리지를 확인한 뒤 확정(연구 문서 §5, `OPEN_QUESTIONS.md` Q-FONT). 확정 전에는 손글씨를 쓰지 않는다.
- 손글씨는 **장식 용도(제목·질문 카드·인용)** 에만. 긴 본문·입력창은 Pretendard.
- 문구는 해요체, 어르신 대상 문구는 한 문장 한 줄을 목표(토스 라이팅 원칙). 문구는 전부 문구 파일 키 참조.

## 5. 간격·라운드·모션 (초안)

- 터치 타깃 최소 **48×48px**(어르신 화면은 56px 이상 권장). 주요 버튼은 화면당 하나.
- 라운드·간격 스케일은 Phase 0에서 hamkke 스케일을 기준선으로 이식하고 값이 바뀌면 이 문서를 갱신.
- 모션: **의미 있는 것만**. 스프링/이징 곡선은 Phase 0 토큰 파일에 이름과 값을 먼저 정의하고 그 이름으로만 사용(임의 곡선 금지). `prefers-reduced-motion`을 반드시 존중. 어르신 화면에서는 모션을 더 줄인다(전환은 짧고 예측 가능하게).
- 시그니처 순간 후보: "별 하나"(1비트 신호) 전달, 이야기 답변 완료(정원에 새 잎/별이 켜지는 정도). 상세 시안은 폴리시 단계에서 목업으로 먼저 확인받는다.

## 6. 레이아웃 원칙

- 하단 3탭(오늘/이야기/우리) + 상세는 시트. 화면당 하나의 초점. 2단 비대칭·사이드바 금지.
- **오늘(봄)**: paper 배경, 봄 색은 배지·칩. **이야기(별)**: navy 계열 배경(별의 밤), 골드 강조. **우리**: silver 연결 요소로 두 영역을 잇는다. 탭 전환 시 배경 톤이 급변하지 않도록 전환 모션을 설계한다(눈부심 방지, 어르신).
- 어르신 모드(역할 = grandparent 기본): 글자 크게, 요소 수 최소, 위험 동작(삭제) 2단 확인, 되돌리기 제공.

## 7. Do / Don't

- Do: 꽃+남색 별 실루엣이 작은 크기에서도 유지, 남색·아이보리를 넓은 면적으로, 골드는 작은 강조에만.
- Don't: 모든 요소에 파스텔 동시 적용, 별·꽃 반복 패턴, UI 전체 그라디언트·그림자, 워드마크 비율·간격 임의 변경, "귀여운 아이 앱"과 "추모 앱" 양극단으로 치우치기(봄/별 균형이 핵심).

## 8. 접근성 체크 (구현 시 게이트)

- 모든 텍스트 대비 AA 이상, 본문은 가능하면 AAA. 토큰 조합은 대비 테스트(단위 테스트로 표의 값 검증)를 만든다.
- 색만으로 정보를 전달하지 않는다. 키보드·스크린리더 지원, 포커스 표시.
- 실기기 확인: 실제 어르신 사용 테스트 계획을 `PROGRESS.md`에 남긴다(자동화 도구로 대체 불가).

## 9. 화면 규칙 (1차 자료 정독 반영, 2026-10-01 · 초안)

근거: [`design-research/2026-10-01-primary-sources.md`](design-research/2026-10-01-primary-sources.md) §7(규칙 후보 32개)·§8(모션 토큰 후보). 아래는 그중 **화면에 바로 쓰는 규칙**을 화면 단위로 옮긴 것이다. 수치가 들어간 모션 값은 **토큰 후보**일 뿐 확정이 아니다(사용자가 고른 뒤 §5를 갱신). `[ ]` 안은 출처 약칭.

### 9.1 공통

1. **모션은 빈도로 정한다** — 하루 수십 번 쓰는 것(탭 전환·목록·스크롤)은 무모션 또는 페이드만, 시트·토스트는 표준 모션, 마일스톤·"별 하나"·이야기 완료 같은 드문 순간에만 즐거움 [Emil·Rauno·Josh]. UI 모션 300ms 미만, 누름·토글 같은 마이크로는 200ms 이하, `transform`/`opacity`만, 중단 가능, `ease-in` 금지 [Emil·SEED].
2. **감소 모션이 기본값** — `prefers-reduced-motion: no-preference`일 때만 움직임을 켠다. 감소 모드는 이동 없이 페이드만. 2초 넘는 애니메이션·5초 넘는 자동 움직임 금지, 앱 설정에 "움직임 줄이기"를 둔다 [Josh·SEED·WCAG 2.3.3].
3. **버튼은 버튼처럼 보인다** — 그림자 대신 윤곽선(1.5px 이상, 대비 3:1) 또는 면. 아이콘 버튼은 반드시 글자 라벨을 함께, 보이는 라벨 = 접근성 이름 [서울 고령층 표준·KWCAG 6.5.3·WCAG 1.4.11].
4. **실행은 손을 뗄 때**, 누름 피드백은 짧게(150ms 안팎) [KWCAG 6.5.2·SEED].
5. **모든 드래그·스와이프에 버튼 대안** — 시트 [닫기], 사진 넘김 화살표, 토스트 닫기 [KWCAG 6.5.1·WCAG 2.5.7].
6. **시간제한 없음** — 작성 중 글은 사라지지 않게(초안 자동 저장), 로그인은 기억 테스트 없이(카카오·초대 링크) [KWCAG 6.2.1·7.3.3].
7. **삭제는 확인 또는 되돌리기** — 사진은 되돌리기 토스트, 이야기·사람·Space는 확인(어르신은 2단계) [Vercel WIG·§6].
8. **문구**: 해요체·능동형·긍정형, 버튼은 다음 행동을 말한다("이야기 보내기"), 버튼·제목에 마침표 없음, 숫자는 아라비아 숫자, 다이얼로그 왼쪽 버튼은 [닫기] [토스·SEED]. 어르신 대상 경어 수준은 `OPEN_QUESTIONS.md` Q-HONOR.
9. **글자**: 입력창 16px 이상(어르신 18px 이상), 확대를 막지 않는다, 글자 크기는 rem. 200% 확대·320px 폭에서 깨지지 않는다 [WCAG 1.4.4·1.4.10].
10. **대비**: 텍스트 4.5:1 필수, 본문 7:1 목표. `ink-muted`(4.9:1)는 어르신 화면 본문에 쓰지 않는다(보조 정보만).

### 9.2 오늘 (봄)

- 한 화면의 주인공은 **사진**. 기록 단위(Moment) 하나 = 카드 하나, 카드 안에 사진·한 줄 글·누가·언제·반응(좋아요·댓글 수, 글자 라벨 동반).
- 아이·반려동물 필터는 상단 칩 한 줄(봄 색은 **선택된 칩 하나**의 면에만 — §3 규칙 2).
- 마일스톤은 피드 안 작은 띠(칩 + 문장)로. 달성 순간의 반짝임은 마일스톤에만(전체 2초 이하, 감소 모드에서는 정지) [Josh Sparkles].
- 새 사진은 자리에 부드럽게 안착(여러 장이면 간격 등장) [Emil stagger·spring].
- 기록하기 버튼은 화면당 하나(+ 아이콘 단독 금지, "기록하기" 라벨).

### 9.3 이야기 (별)

- 맨 위에 **질문 카드 하나**(오늘 답할 질문 또는 가족이 물어본 질문) + 주 행동 [답하기]. 질문 카드는 골드를 작은 강조(표식·테두리)로만.
- 아래는 **이야기 정원**: 이야기마다 상태 3단계 은유(질문 받음 → 답하는 중 → 답 완료/별) — 의미는 반드시 글로도 쓴다 [Maggie 성장 단계 — 매핑은 우리 해석].
- 손그림 일러스트는 빈 화면·질문 카드에만, 그림 위에 글자 금지(Q-ILLUST — 그릴지·생성할지·안 쓸지 사용자 결정).
- "별 하나"는 누르면 짧게 튀었다 돌아오는 정도(boop) [Josh Boop].
- 배경은 §6대로 navy가 기본. 탭 전환 눈부심을 줄이는 대안(이야기 탭도 paper)은 목업 안 C로 비교한다(§6과 다르면 사용자 결정 후 갱신).

### 9.4 우리

- 맨 위 한 초점: **다음 가족 일**(D-day 카드). 그 아래 가족 구성원(세대별, 관계 표시명), 그 아래 달력·설정 진입.
- silver는 두 영역(봄·별)을 잇는 선·테두리에만. 기념(별이 되신) 구성원은 색이 아닌 표식·문구로 구분.

### 9.5 어르신 온보딩

- **한 화면 한 가지**, 현재 단계 + "2단계 남았어요" 같은 남은 단계 안내, 이전·그만하기 항상 가능 [서울 고령층 표준 2-2·2-3].
- 순서 초안: 초대 확인(누가 초대했는지 사진·이름) → 카카오로 시작하기(한 번) → 어떻게 불러드릴지(관계 고르기, 자유 입력 가능) → 글자 크기 고르기(미리보기) → 가족 사진 보러 가기.
- 이메일·비밀번호 입력 없음, 반복 입력 없음(초대에 이미 있는 정보는 미리 채움) [KWCAG 7.3.3·7.3.4].
- 주 버튼 높이 56px 이상, 본문 20px 안팎에서 시작(정확한 값은 토큰 확정 때).

### 9.6 시트·토스트

- 상세는 아래에서 올라오는 시트, 같은 방향으로 닫힌다. **항상 보이는 [닫기] 버튼**, 드래그 닫기는 보조(임계값 후보: 높이 25% 또는 0.4px/ms, 스크롤 직후 100ms 잠금 — Vaul 상수) [Vaul·KWCAG 6.5.1]. Vaul은 저장소가 "unmaintained"라 의존성 대신 상수·동작만 참고한다.
- 시트·모달은 `overscroll-behavior: contain`, 하단 safe-area 여백.
- 토스트는 하단 하나(최대 3개), `aria-live="polite"`, 탭이 숨으면·누르는 동안 타이머 정지, 닫기 버튼 동반. 중요한 결과는 토스트에만 두지 않는다. 어르신 화면 표시 시간은 기본 4초보다 길게 검토 [Sonner·Vercel WIG].
- 로딩 표시는 150–300ms 지연 후, 보이면 최소 300–500ms, 스켈레톤은 최종 레이아웃과 같게 [Vercel WIG].
