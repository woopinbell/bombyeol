- 오른쪽 설정: 밝게/어둡게, 글자 크게, 움직임 줄이기, 느리게 보기 ×5, 시트 350ms(선택)/500ms, 토스트 6초(선택)/4초. URL로도 고정: `?theme=dark&motion=reduce&slow=on&sheet=vaul&toast=short&text=large`.
