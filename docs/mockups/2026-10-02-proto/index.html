데모 동작

해볼 것

  1. 오늘 탭 사진을 눌러 시트 열기 → [닫기], Esc, 아래로 끌기(높이 25% 이상 또는 빠르게 튕기기)로 닫기. 조금만 끌면 제자리로.
  2. 시트에서 댓글 보내기 → 댓글 등장 + 토스트. 토스트 위에 손을 올리면 시간이 멈추고, 아래로 밀면 닫혀요.
  3. 이야기 탭의 별 버튼 → "별 하나" boop(스프링). 다시 누르면 취소.
  4. 버튼을 꾹 누르면 2px만큼 줄어들어요(크기에 상관없이 같은 거리).
  5. 움직임 줄이기를 켜고 같은 동작을 반복 — 이동 없이 페이드만.
