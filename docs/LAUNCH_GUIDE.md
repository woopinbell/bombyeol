# 봄별 - 출시 마무리 안내서 (사용자용)

2026-10-05 사용자 결정으로, 세션은 "출시 직전 단계"까지만 혼자 끝냈다(PROGRESS "종착역"). 이 문서는 **사용자만 할 수 있는 일**을 순서대로 모은 것이다. 위에서부터 하나씩 하면 된다. 각 단계가 끝나면 맨 아래 "세션에게 할 말"을 새 세션에 붙여 넣는다.

- 돈이 드는 일은 표시해 두었다. 메뉴 이름은 서비스가 바꿀 수 있어 참고용이다(자세한 항목은 `COST_GUARDS.md` §4).
- 키, 비밀번호는 대화에 붙여 넣지 않는다. 대시보드나 `wrangler secret put`으로만 넣는다(`CLOUD_SESSION.md` §3).

## 0. 쌓인 작업 머지 (언제든)

- [ ] GitHub에서 열린 PR(초안이면 "Ready for review" 뒤)을 **Create a merge commit**으로 머지한다. 세션의 머지는 권한 검사에서 막혀 있다.
  - 매번 하기 번거로우면 Claude Code 설정에 GitHub PR 머지 허용 규칙을 한 번 더하면 이후 세션이 CI 통과 뒤 직접 머지한다.
- [ ] 머지되면 새 세션에 "스테이징 배포"라고 말한다. 마이그레이션이 있으면 GitHub Actions가 스테이징 DB에 먼저 적용한다.

## 1. 가족 시험 전 (본인 가족이 실제로 쓰기 시작하기 전)

순서대로. 1-1~1-3은 대시보드에서 몇 분이면 끝난다.

- [ ] **1-1 Cloudflare Workers Paid 전환** (돈: 월 기본료) - 무료 플랜의 CPU 한도 초과가 스테이징에서 약 0.9% 나왔다. 실제로 쓰면 가끔 오류 화면이 뜬다. 결정은 2026-10-02에 이미 됨(Q-PLAN).
- [ ] **1-2 사용량 알림** - Cloudflare 대시보드 Notifications에서 Usage Based Billing 알림을 Workers, R2 각각에 낮은 임계값으로(받는 곳: 내 이메일).
- [ ] **1-3 Supabase 플랜 확인** - 무료면 오래 안 쓰면 DB가 일시 중지된다. 유료(Pro, 돈)로 올리면 Spend Cap을 켠 채로 둔다. Firebase는 무료(Spark) 그대로, 결제 계정 연결하지 않기.
- [ ] **1-4 카카오 JavaScript 키** - 카카오 개발자 콘솔에서 JavaScript 키를 복사해 claude.ai/code 환경 설정의 환경변수 `NEXT_PUBLIC_KAKAO_JS_KEY`에 넣는다(이름과 형식은 `ENV_MANIFEST.md`). 플랫폼 > Web 사이트 도메인에는 지금 쓰는 주소만. 그 뒤 새 세션에 "카카오 키 넣었어, 재배포"라고 말한다. 없으면 어르신 초대는 링크 복사로만 된다.
- [ ] **1-5 어디서 가족 시험을 할지 정하기**
  - (가) 지금 스테이징 주소 그대로: 바로 시작 가능. 단 스테이징 DB는 개발용이라 나중에 프로덕션으로 옮기면 가족 기록을 다시 올려야 한다(내려받기 ZIP은 있음).
  - (나) 프로덕션을 먼저 만들기(권장, 기록을 계속 쓸 거라면): 아래 2-1~2-4를 먼저 한다. 도메인이 없으면 workers.dev 주소로도 된다.
  - 가족 시험 도중 주소를 바꾸면 홈 화면 앱과 알림을 새 주소로 다시 설치해야 한다(기록은 그대로).
- [ ] **1-6 실기기, 어르신 확인** - `PROGRESS.md` "미완료 검증"과 아래 목록. 이상한 곳은 스크린샷과 함께 새 세션에 말하면 고친다.
  - 알림(안드로이드, 아이폰 홈 화면 앱), 알림을 눌러 기록 펼치기, 아침 9시 가족의 날 알림
  - 카카오톡 공유, iOS 사진 올리기, 아이폰, 안드로이드 영상의 위치 정보가 지워지는지(올린 영상을 내려받아 사진 앱의 정보에서 위치 확인)
  - 기기 글자 크기 최대 + 앱 "더 크게"로 오늘, 이야기, 우리 탭
  - 스크린리더(VoiceOver, TalkBack)로 사진 기록 열기, 좋아요, 이야기 답하기
  - 어르신 한 분이 초대 링크로 들어와 도움 없이 사진 보고 마음 남기기, 이야기 하나 답하기(막힌 곳 기록)

## 2. 프로덕션 만들기 (가족 시험을 프로덕션에서 하거나, 공개 직전)

세션은 리소스를 만들지 않는다. 아래는 사용자가 직접 실행한다(로컬 터미널, 저장소 main 체크아웃, `npx wrangler login` 된 상태).

- [ ] **2-1 Supabase 프로덕션 프로젝트** (돈: 플랜에 따라) - 스테이징과 **다른 프로젝트**, 지역은 서울. 연결 문자열 두 개를 챙긴다: 직결(Hyperdrive용), Session pooler(IPv4, GitHub Actions용).
- [ ] **2-2 리소스 만들기** - `scripts/production-setup.sh https://<주소> "<직결 연결 문자열>" --yes`. R2 버킷 `bombyeol-media`(수명주기, CORS 포함)와 Hyperdrive `bombyeol`을 만들고 다음 할 일을 출력한다. 주소는 도메인이 없으면 `https://bombyeol.<계정>.workers.dev`.
- [ ] **2-3 설정 커밋** - 출력된 Hyperdrive id를 `wrangler.jsonc`의 `env.production.hyperdrive`에, 주소를 `APP_ORIGIN`에 넣는다. 도메인이 있으면 `routes`(custom_domain)도. 직접 고쳐도 되고 새 세션에 "Hyperdrive id는 대시보드에 있어, 프로덕션 설정 커밋해"라고 해도 된다(id는 비밀이 아니다).
- [ ] **2-4 시크릿 등록** - `npx wrangler secret put <이름> --env production`으로 하나씩. `AUTH_SECRET`은 새로 만든다(`openssl rand -base64 33`). 카카오, Google 로그인 키, R2 키(이 버킷에만 권한 있는 새 토큰), Firebase 서비스 계정. **클라우드 세션 환경변수에는 넣지 않는다.**
- [ ] **2-5 DB 마이그레이션** - GitHub 저장소 Settings > Secrets에 `PRODUCTION_DATABASE_URL`(Session pooler)을 넣고 Actions에서 "Migrate production DB"를 수동 실행.
- [ ] **2-6 로그인 콘솔에 주소 추가** - 카카오: Web 사이트 도메인과 Redirect URI `https://<주소>/api/auth/callback/kakao`. Google OAuth: 승인된 리디렉션 URI `https://<주소>/api/auth/callback/google`.
- [ ] **2-7 배포** - `npm run cf:deploy:production` 뒤 `AUTH_SECRET=<프로덕션 값> node scripts/smoke-staging.mjs https://<주소>`(스모크는 주소를 인자로 받는다). 또는 새 세션에 "프로덕션 배포"라고 말한다(세션 환경에 프로덕션 키가 없으므로 스모크 마지막 단계만 사용자가).

## 3. 공개 직전 (가족 밖으로 열기 전에만)

- [ ] **3-1 사업자, 결제** - 무료로 먼저 연다(2026-10-05 결정). 유료를 시작할 때 사업자 등록 여부를 정하고 Q-PAY(`research/2026-10-01-q-pay-providers.md`)를 고른 뒤 새 세션에 Phase 8을 시킨다.
- [ ] **3-2 도메인** (돈) - `bombyeol.*` 확보, "봄별" 상표, 앱스토어 이름 충돌 확인(Q-DOMAIN). 정하면 2-3, 2-6을 새 주소로.
- [ ] **3-3 약관, 처리방침 빈칸** - 코드의 `src/content/legal/terms.ts`, `privacy.ts`에 대괄호로 남은 칸: 운영자 이름, 약관 주소, 웹 주소, 연락처(이메일), 개인정보 보호책임자(이름, 직함, 연락처), 처리 기한(기본 [10]일), 보관 기간 [기간], 서비스 종료 예고 [30]일, 내부 관리 계획. 값을 새 세션에 말하면 채우고 `src/lib/consents.ts` 버전과 시행일을 함께 올린다(테스트가 확인). 기존 사용자는 한 번 다시 동의한다(정상).
- [ ] **3-4 전문가 검토** - 채운 약관, 처리방침을 개인정보, 아동 정보(만 14세 미만), 민감정보(임신) 기준으로 검토받는다. 원문 초안과 "(확인 필요)" 표시는 docs 브랜치 `legal/`. **검토 전에는 공개하지 않는다.**
- [ ] **3-5 마지막 확인** - `COST_GUARDS.md` §4 체크리스트가 모두 체크인지, 1-6 실기기 확인을 프로덕션 주소로 한 번 더.
