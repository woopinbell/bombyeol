# 디자인 폴리시 기준선 2차 (2026-10-05, main 290f2be)

1차 기준선(`design-handoff/2026-10-05/screens/`)은 사진 없는 시드, 영어 브라우저로 찍었다. 2차는 실제 업로드 경로로 사진 18장(기록 5개, 1장, 2장, 3장, 5장, 9장 묶음), 좋아요와 댓글, 긴 이름(외할아버지(제주), 김영수사랑하는우리할아버지, 긴 가족 이름), 반려동물, 마일스톤 3개, 일정 2개, 빈 가족, 가족 없는 새 사람을 넣고 **한국어 브라우저(ko-KR, Asia/Seoul)** 로 찍었다. 도구는 `dev-notes/local-ui-check/`(seed.test.ts, photos.mjs, shots.mjs).

- `baseline-{light,dark,large320}-{1,2}.png`: 16화면 x 3모드 모아보기(각 화면 위쪽 1100px까지). 원본 전체 화면은 스크래치에만 있었다(용량).
- `findings-1-layout.png`, `findings-2-content.png`, `findings-3-empty.png`: 아래 목록의 해당 부분.

## 어긋난 곳 (사용자에게 보인 목록, 우선순위 확인 대기)

A. 깨짐 (글자 더 크게 + 320px) - 동작은 그대로, 배치만
- **A1 이야기 탭 거르기 칸 글자 겹침**: "할머니"와 "외할아버지(제주)"가 겹친다. 원인: 항목 `li`가 `flex-1 min-w-20`이라 줄어드는데 글자는 `whitespace-nowrap`(story/page.tsx, 오늘 page.tsx 같은 구조). DESIGN §9.1-9(320px에서 깨지지 않는다) 위반.
- **A2 오늘 탭 거르기 칸**: 넘친 항목("보리")이 잘려 끝에 점 하나만 보이고 옆으로 넘길 수 있다는 단서가 없다.
- **A3 짧은 말이 두 줄로 꺾임**: 우리 탭 "12일 / 뒤", "할머니 / 생신", 긴 이름 줄의 "고치기 >"가 오른쪽 여백 밖으로, "할머니 할아버지 초대하기"(기존 U2), 이야기 "직접 / 쓰기", "받은 별 / 2", 달력 "2026년 / 10월", "다음 / 달", 설정 "기기 / 따라", 반려동물 "사진 / 고르기", 아이 목록 "2027년 3월 / 1일 예정". 버튼, 숫자 + 단위는 꺾이지 않게.

B. 문구, 정보 표시
- **B1 일기 표시가 기록마다 다름**: 시간이 글 길이에 따라 다음 줄 또는 같은 줄, 사진 기록은 "엄마, 시간"인데 일기는 위에 "엄마의 일기". 사진 없는 일기, 마일스톤 띠, 다음 기록 사이 경계가 흐리다(기존 T2).
- **B2 0 표시**: "좋아요 0", "댓글 0", "별 0"(기존 T3).
- **B3 저장 공간 막대**: 2GB 중 1MB면 막대가 빈 테두리만 보인다(기존 U1).
- **B4 새 가족 이야기 탭**: 어르신도 아이도 없는 가족에 "손주가 태어났다는 소식을 들었을 때..." 질문과 [답하기]가 나온다(엄마가 답하게 되는 셈).

C. 빈 화면 (일러스트 보류와 묶임 - Q-ILLUST, B2 브랜드)
- C1 빈 오늘 허전함(기존 T1), 버튼 이름이 "사진 올리기"(평소 "기록하기").
- C2 빈 이야기 글자뿐(기존 S2), C3 로그인 가운데 빈 공간(기존 O1), C4 다크 빈 화면 밋밋(기존 C1).

1차 목록에서 정리된 것
- O2 날짜칸 영문 mm/dd/yyyy: 앱 문제 아님. 캡처 브라우저가 영어였기 때문이고, 한국어 브라우저에서는 "연도. 월. 일.", "2026. 01. 01."로 나온다(실기기 확인만 남음).
- S3 이야기 타일이 하단 탭에 가림: 이번 시드(타일 3개, 390px)에서는 맨 아래 타일이 탭 위로 다 보였다. 재현 조건 다시 확인 필요.
- S1 질문 카드 일러스트: 보류 그대로.

참고(어긋남 아님, 판단 필요): 글자만 있는 보조 버튼(다른 질문, 거두기, 임신 기록 고치기, 지우기)은 테두리가 없다. DESIGN §9.1-3 "버튼은 버튼처럼"과 §10.3 "테두리는 누를 수 있다는 신호" 사이에서 보조 행동을 어떻게 볼지 결정이 필요하다.
