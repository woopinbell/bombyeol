# 봄별 Brand Guide

## Chosen direction

**1번 심볼 + 절제된 인간적 워드마크**를 기준으로 한 브랜드 에셋입니다.

핵심 원칙은 **귀여운 봄의 생동감**과 **차분한 별의 기억성**을 동시에 유지하는 것입니다.

### Symbol

꽃잎 색은 봄의 성장과 오늘을, 깊은 남색 별은 오래 남는 기억을 나타냅니다. 작은 별빛은 두 시간축이 같은 공간에서 만난다는 의미로 사용합니다.

### Wordmark

한글 `봄별`은 둥글고 친근한 형태를 기본으로 하되, 너무 유아적으로 보이지 않도록 간결한 구조를 유지합니다. 작은 골드 곡선은 감성 요소를 더하되 기능성 UI를 방해하지 않도록 최소한으로 사용합니다.

## Usage

- `logo/primary.svg`: 밝은 배경의 기본 로고
- `logo/primary-dark.svg`: 어두운 배경의 기본 로고
- `logo/symbol.svg`: 앱 아이콘/프로필/좁은 영역
- `logo/wordmark.svg`: 텍스트 중심 헤더
- `logo/monochrome.svg`: 단색 인쇄 또는 제약 환경
- `icon/*`: 웹 앱/PWA 아이콘 파생본
- `og/og-image.png`: Open Graph / SNS 공유 이미지
- `brand/tokens.json`: 확정 토큰 v1 원본(2026-10-02, DESIGN.md §12)
- `brand/tokens.css`: 같은 값의 CSS 변수판, `brand/check-contrast.py`: 대비 검사

## Typography

본문/인터페이스: **Pretendard** 권장.

브랜드 워드마크: 에셋 SVG 내부의 둥근 한글 스타일을 유지하고, UI 본문과 혼용하지 않습니다.

## Do / Don't

### Do

- 아이콘은 작은 크기에서도 꽃 + 남색 별 실루엣이 유지되게 사용
- 봄 색상은 포인트 중심으로 사용
- 남색/아이보리를 넓은 면적으로 사용해 신뢰감 확보
- 골드는 작은 강조점에만 사용

### Don't

- 모든 요소에 파스텔 색상을 동시에 적용하지 않기
- 별/꽃을 반복 패턴처럼 과하게 사용하지 않기
- 그라디언트와 그림자를 UI 전체에 확장하지 않기
- 워드마크의 비율이나 심볼의 간격을 임의로 변경하지 않기
